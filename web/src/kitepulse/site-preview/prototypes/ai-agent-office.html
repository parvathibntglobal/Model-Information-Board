The Office: an AI agent virtual office for your coding team

Who is at work, whose agent needs a person, and who is close to a Claude limit, on one page.

The Office is Kite Pulse's AI agent virtual office: a desk per person, grouped by team, showing whether they are online, away or offline, with a marker when work is stuck or a plan limit is near. It is the console's home page for every role, and detail shows only for people in your scope.

It is built from the session history ten AI coding tools already keep, so nobody types anything in. For how many agents one person is running, Agents in parallel goes a level deeper.

Who is at work, and whose agent needs a look?

An AI agents office answers a lead's first question: is the work moving? The Office is the first page anyone sees after signing in.

  • A desk per person, grouped by team, each with the AI tool they use.
  • Online, away or offline. Online means the desktop program checked in within the last 10 minutes.
  • A marker when work is stuck, or when someone is near or at a Claude plan limit.
  • Presence is shared with everyone. Stuck and plan-limit detail shows only for yourself, the people you manage, and admins.

How many Claude Code parallel agents is one person running?

Developers who run parallel agents keep several Claude Code sessions going, and each main session can start sub-agents of its own. Agents in parallel, on a developer's page, is where you monitor parallel AI agents for one person.

  • How many AI agents and sub-agents are working right now.
  • The state of each: working, waiting for the developer, or waiting for permission.
  • A lane chart for any past day: one lane per agent, and the most that ran at once.
  • Admins can open it for anyone. Managers see it for themselves.

What needs a person today?

  • Needs attention is one inbox, opened from the top bar, for everything waiting on you. A developer sees their own data collection; managers and admins see more groups.
  • Team Overview is the AI agent dashboard for managers and admins: who is online and who is coding right now, active time and sessions today against a typical day, who needs attention (failing uploads, backlog, old app version) and each person's current project. It refreshes every 30 seconds, and past days can be picked.
  • Plan headroom lists who is close to a Claude limit, worst first, when a desk marker is not enough.

What The Office does not do

  • It does not start, stop or steer agents. It reads what the tools recorded.
  • It does not say whether the code is good. A desk describes what happened.
  • It is not a notification hook, and it does not promise a push alert when Claude Code is waiting for input or finishes. Agents in parallel shows which agents are waiting when you look.
  • Plan markers cover Claude Code only. Other tools show "Not reported by this tool" on Plan headroom.

Questions about The Office

How can I see what my team's AI agents are doing right now?

Open The Office, the home page of the Kite Pulse console. It shows a desk per person grouped by team, with online, away or offline status and markers for stuck work or plan limits. Everyone sees presence; detail shows only for people in your scope.

How many AI agents is my team running right now?

Agents in parallel, on each developer's page, counts the AI agents and sub-agents working now and gives each one's state: working, waiting for the developer or waiting for permission. Admins can open it for anyone; managers see it for themselves.

Which Claude Code features (sub-agents, plan mode, MCP tools) does my team use?

The Agent features tab of Team AI Usage shows which Claude Code agent features sessions used, including sub-agents, background commands, plan mode, worktrees and MCP tools, by session and by developer. Managers see their own reporting line; admins see everyone.

Can developers see each other's desks?

Developers see The Office like everyone else, but for colleagues outside their scope they see presence only: name, AI tool and whether the person is online or away. Stuck work and plan-limit detail show only for yourself, the people you manage, and admins. Admins can restrict this further per role on Roles & Permissions.

Do the plan-limit markers cover every AI tool?

No. Plan limits come from Claude Code only. Desks of people on other tools show presence and stuck work, but no plan-limit marker.
