Team status dashboard

What is my team working on right now?

  • Team Overview: who is online and coding now, active time today against a typical day, and each person's current project. Refreshes every 30 seconds.
  • Who needs attention: failing uploads, backlogs, old app versions.
  • The Office: a desk per person, grouped by team, with online, away or offline status. A virtual office for remote teams.
  • Leave & On-Call records leave and rotas so a quiet week is not misread. It is not a vacation tracker for teams.

Questions about the team activity dashboard

How do I create a weekly AI usage report for my team?

In Kite Pulse an admin sets up a scheduled report: the Company report, or one developer's report, emailed daily, weekly or monthly as a PDF or CSV. The Company report compares the period with the one before. Email has to be configured on your server first.

Can I control who can access individual-level usage data and organization-wide reports?

Yes. There are three access roles: Developer sees their own pages, Manager sees their whole reporting line, and Admin sees everyone. The server enforces this, not just the screen. Admins can adjust each page per role on Roles & Permissions, and downloading the Company report is for admins by default.

Does AI coding analytics include an audit log of admin actions?

Kite Pulse has a read-only, filterable Audit Log of sign-ins, failed sign-ins, lockouts and admin changes, covering over 100 kinds of action. It is kept indefinitely by default; a retention period (365 days by default) applies once the server operator enables deletion.

Can we configure how long developer analytics data is retained?

Yes. On Retention, admins set how long plan-usage history is kept and the windows for raw content, derived data and audit history. Those windows are applied once the server operator enables deletion on the server. Until then, data stays.

Does AI coding analytics support sign-up by company email domain?

Kite Pulse does. On Login & Registration an admin chooses admin-created accounts (the default), sign-up by company email domain, or open sign-up with admin approval. Sign-in is email and password.

Can I export reports or integrate the data with our existing analytics and finance systems?

You can export. The Company report downloads as CSV or PDF, the Plan usage report as Excel, and an admin can export one person's data as a file. For a live connection, Kite Pulse has an Agent API and MCP server that are available when the server operator turns them on; they are off on a standard install.
