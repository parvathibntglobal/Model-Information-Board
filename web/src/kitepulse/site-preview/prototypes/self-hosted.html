Self-hosted developer analytics for AI coding teams

Kite Pulse runs on a machine you choose, and your AI coding data stays there.

Kite Pulse is self-hosted developer analytics: it reads the session history ten AI coding tools keep on each developer's computer, masks secrets, and sends it only to a Kite Pulse server your team runs. There is no vendor cloud in between. You choose where the server lives: one computer, your local network, an Ubuntu server or your own AWS account.

Safeguards for developers

Before anything is sent

  • No server address is built in. The program will not run until it is given your team's own server.
  • No session content uploads until the developer confirms their projects, and an approver signs off where required.

While it runs

  • Secrets are masked on the computer and again on the server. For Cursor and OpenCode chat text, on the server only.
  • Each person sees every data point collected about them on Privacy, whether it is on, and who can see it.
  • Updates come only from your own server, checked for size and integrity before install.

What Kite Pulse does not do

  • There is no hosted version run by the vendor, and no vendor cloud between your developers and your server.
  • The desktop program has installers for Windows and macOS only.
  • The app does not encrypt stored sessions itself; use your own disk encryption, or S3 on AWS.
  • It does not delete old data until the server operator enables deletion.
  • Sign-in is email and password; there is no sign-in through a company identity provider.
  • It does not need an AI service. AI labelling stays off until an admin sets it up.
  • Licence: proprietary (NTGLOBAL SOLUTIONS).

Self-hosted questions

Is there a self-hosted tool to monitor AI coding tool usage?

Yes. Kite Pulse reads the session history ten AI coding tools, including Claude Code and Cursor, keep on each developer's computer, masks secrets, and sends it to a server your team runs. There is no vendor cloud in between.

Can AI coding analytics be self-hosted on our own infrastructure?

Yes, and that is the only way it runs: on one computer, on a local network, on an Ubuntu 22.04 or 24.04 server, or in your own AWS account, each set up by one command or script. You can also run the server alone.

What infrastructure does a self-hosted AI coding analytics server need?

A machine you run, PostgreSQL, and local disk or Amazon S3 for stored data. Email features need a mail server configured on the server. Kite Pulse does not publish CPU, memory or disk sizes; ask for them in a demo.

Can a self-hosted AI usage tracker scale to thousands of developers?

Kite Pulse has no published, tested figure for a number of developers. What it gives you is the means to watch the server as you grow: Infrastructure checks for memory, backlog, disk and the database, Server Storage by person and project, and stored data in Amazon S3 if you choose.

Does any session data leave our network?

Session data goes only to the server you run. If an admin sets up AI labelling, which is off by default, scrubbed text is sent to the AI provider through OpenRouter (default policy: zero data retention).
