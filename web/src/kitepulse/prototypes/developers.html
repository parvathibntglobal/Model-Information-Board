How Kite Pulse helps developers: your own Claude Code dashboard

Every role, including Developer, has pages about its own work. Each block links to the page that covers it in depth.

Is my work being captured?

  • Workspace lists each project as detected, waiting to sync, syncing, processing, processed or failed.
  • Nothing uploads until you confirm your projects in the Onboarding Wizard.
  • My Projects lets you confirm, rename, split or remove a project; Pending Requests follows your change requests.
What each of the ten tools provides

How close am I to my Claude plan limit?

  • Workspace shows your Claude plan usage, from the figures Claude Code saves on your computer. No login or password is read.
  • Figures are as fresh as Claude Code's last save, unless an admin turns on the optional background refresh, which uses no tokens.
  • Claude Code only; other tools show "Not reported by this tool".
Plan headroom for the whole team What Kite Pulse reads from Claude Code

Where does my AI time go?

  • My Activity shows when, for how long and with which tools you worked.
  • My Sessions lists every session with a summary and a detailed view, filtered by tool, model or session type.
  • Cursor AI usage stats sit beside Claude Code's, with input and output tokens.

Where are my Claude Code token usage stats?

  • Kite Pulse counts tokens per tool, model, project and day.
  • They appear on Team AI Usage, a manager and admin page by default.
  • Estimated cost per developer is shown to admins only.
Token usage per developer, explained

Am I getting better?

  • My Scorecard & Insights leads with "Top 3 to act on": a verdict, what to try and the evidence, or "not enough data".
  • Work-pattern facts, and a working style worked out by fixed rules.
  • Private prompt statistics: most repeated prompt, most cryptic prompt, thank-you count and reply pace.
Developer analytics without reading source code

Who sees my data, and can I run it alone?

  • The Privacy page shows everything recorded about you, whether it is on, and who can see it.
  • Your manager sees your pages for their reporting line, without your private prompt statistics, which only you see.
  • Alone, one command sets everything up on one computer, reachable from that computer only.

Questions developers ask

How can I track my Claude Code usage?

Install the Kite Pulse app and point it at a Kite Pulse server, your team's or one on your own computer; it reads the session history Claude Code already keeps. After you confirm your projects, Workspace shows what is being collected and your Claude plan usage.

How do I monitor my Claude Code usage?

Check Workspace for your Claude plan usage and each project's collection status, and My Activity for when and with which tools you worked. Plan figures are as fresh as Claude Code's last save unless an admin turns on the background refresh.

How do I check Claude Code usage stats?

Open My Sessions for every session with a summary and filters, and My Scorecard & Insights for work-pattern facts such as peak hour and longest streak. Token counts per model and day are on Team AI Usage, which managers and admins see by default.

Who can see my Kite Pulse data?

You see everything about yourself; your manager sees your pages for their reporting line and admins see everyone, but your private prompt statistics are shown only to you. The Privacy page lists what is recorded and who can see it.

Does it cover Cursor and the other AI tools I use?

Yes, Kite Pulse reads ten AI coding tools: Claude Code, Codex, Gemini CLI, Cursor, GitHub Copilot Chat in VS Code, Cline, Roo Code, Kilo Code, OpenCode and Aider. An admin can switch any off. Claude plan usage covers Claude Code only.

Can I use Kite Pulse on my own, without a team?

Yes. One command sets up the server, background worker, collector and database on one computer, reachable from that computer only.
