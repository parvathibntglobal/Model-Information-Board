Claude Code usage limits: how they work and how to make them last

Claude Code usage limits are the caps on how much you can use Claude Code on a Claude subscription. Paid plans have two: a session limit that resets every five hours, and a weekly limit that resets once a week. Both are shared with Claude chat, and Max plans add a separate weekly limit for Fable.

Claude weekly limits by plan: start with yours

Which limits apply depends on how you pay for Claude Code. Pro and Max have a five-hour session limit and a weekly limit, shared across Claude and Claude Code. Max 5x and Max 20x give five and twenty times Pro's per-session allowance. Team and seat-based Enterprise seats draw from a per-seat allowance whose size depends on the seat tier. With an API key you pay per token instead. Anthropic does not publish fixed message or token counts for any plan.

When do Claude limits reset? The 5-hour and weekly windows

The session limit resets every five hours. On Team and Enterprise seats Anthropic describes it as a rolling five-hour window. The weekly limit is not rolling: it resets at a fixed time each week that is assigned to your account. The help pages do not say exactly when a five-hour window starts, so read the reset times from Claude Code's /usage screen or claude.ai Settings → Usage, then set them below.

How close am I to the limit? Check your remaining usage

In Claude Code, /usage shows your plan usage bars, activity stats and a usage breakdown, and /status shows your remaining allocation. On claude.ai the same bars are under Settings → Usage. Enter the two percentages here to see whether today's session and this week's limit will last at your current pace. This is an estimate from your own numbers: usage is rarely even through a day.

How it works: your pace is the share used so far divided by the time since the window started (five hours, or seven days, minus the time left until the reset you set in step 2). The projection carries that pace to the reset.

Why Claude Code usage runs out fast, and what uses it most

Anthropic lists what drives usage: the length and complexity of your conversations, the features you use, the model, and the effort level. In Claude Code the biggest driver is context: it sends your full conversation with every request, so a one-line question in a session that has been open all day still draws usage for the whole conversation. Plan your week so the weekly limit lasts

A weekly limit runs out on the day you use most. Split what you have left across the days you will actually work before the reset, and keep heavy work, such as long agent runs, for days with room. Your week left comes from step 3 and the reset day from step 2.

Claude Code limit reached: what to do now

What you can do depends on which limit you hit. A session or weekly limit is shared across all models, so switching models with /model does not restore access; after an Opus or Sonnet limit, switching to a model outside that family does. Pick the message you saw.
