What is shadow AI in coding?

Shadow AI is any AI tool used for work without the organisation knowing or approving it. In software teams it usually means developers using AI coding assistants, agents or CLIs on personal accounts or outside the approved list, so code and data go to tools nobody has reviewed.

How Kite Pulse finds shadow AI coding tools

A small background program on each developer's computer reads the session history that AI coding tools already keep. It strips out secrets on the device, then sends the sessions to your own Kite Pulse server. Tool Accounts then shows every tool and account in use, how many people use each one, and when each was last active.

  • Which accounts each tool runs under, including personal and shared ones

Shadow AI questions

How do I find out which AI tools developers use without approval?

Compare your approved list with what is actually running. Vendor admin consoles only show their own tool. A tool that reads AI session history on each developer's computer, like Kite Pulse, shows every supported AI coding tool and account in one place.

How can I find shared or unused AI tool accounts?

Look at how many people use each account and when it was last active. One account used by several people is a shared login. An account with no activity in 30 days is an unused seat.

What is the risk of shadow AI in software development?

Code, secrets and customer data can go to tools nobody has reviewed, under accounts the company does not control. When a developer leaves, their personal account and its history leave with them.

Should we ban unapproved AI coding tools?

Bans tend to push usage out of sight. A short list of approved tools, company-owned accounts and a fast way to request new tools usually works better.
